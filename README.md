# mnseong.github.io

Personal academic website of Minseong Kweon — https://mnseong.github.io

A single static page (`index.html` + `stylesheet.css`) served by GitHub Pages; no build step.
Originally based on [Jon Barron's template](https://github.com/jonbarron/jonbarron.github.io).

- Teaser media live in `images/` (WebP for stills, H.264 MP4 ≤720px wide for videos).
- The CV linked from the page is `data/Minseong_CV.pdf`.
